建立网络连接凭据

首次使用网络功能时，先在设备上开启蓝牙配网窗口，再点击配对。服务会生成并保存本机凭据；重复配对复用同一份凭据。

配对会替换设备当前网络凭据，其他主机的旧凭据将失效。已配对的设备可在上方直接导入已有凭据。

USB 配网只更新 Wi-Fi，不生成网络凭据。中文 SSID 请使用蓝牙；当前 USB shell 输入仅支持 ASCII。
